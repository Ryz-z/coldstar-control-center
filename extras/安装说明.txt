================================================
  隐星控制中心 (Colorful Control Center)  v1.0.5
  适用机型: 七彩虹隐星 P15 系列（蓝天/Clevo 模具）
================================================

【这是什么】
一个面向 Ubuntu/Linux 的控制中心程序，功能对标 Windows 下的
七彩虹 "Control Center"，通过笔记本官方固件接口 (Clevo ACPI/WMI)
直接控制硬件：

  · 风扇：自动(EC) / 静音 / 均衡 / 性能 / 全速 / 自定义温度曲线 / 手动定速
  · 键盘灯：开关、亮度、三区域颜色、8 种硬件灯效（呼吸/循环/舞动/波浪…）
  · 监控：CPU/GPU/硬盘温度、风扇转速、电池、内存
  · 性能预设：省电 / 安静 / 性能 / 影音（ODM 整机策略）

【安装】(任选其一种)
方法一(推荐): 双击 deb 文件 → 点「安装」→ 输入登录密码
方法二(终端):  cd ~/下载
              sudo apt install ./colorful-control-center_1.0.5_amd64.deb

【⚠ 重要：本机开启了 Secure Boot（安全启动）】
未签名的内核模块在开启安全启动时无法加载。安装脚本已自动完成
「生成密钥 → 签名模块 → 登记 MOK」三步，你只需最后重启登记一次：

   1) 安装完成后重启电脑
   2) 重启后出现蓝色 MOK 界面：
      Enroll MOK → Continue → 输入密码: colorful → Reboot
      (如果没有出现蓝色界面: 终端执行一次
       sudo mokutil --import /var/lib/colorful-control-center/mok/MOK.der
       然后再次重启)
   3) 进入系统后即可完整使用

不想走这套流程？也可以开机按 F2 进 BIOS → 关闭 Secure Boot → 保存重启。
（两种方式任选其一，之后永久生效，无需再操作）
※ 如果你已经完成过上面步骤并让模块正常工作，升级版本时无需再做任何登记。

【使用】
· 打开: 应用菜单搜索「控制中心」，或终端执行  colorful-control-center
· 页面: 仪表盘 / 风扇控制 / 键盘灯效 / 系统设置 / 诊断
· 托盘: 关闭窗口不会退出（驻留系统托盘）；右键托盘图标可切换
        工作模式（性能/平衡/安静/自动）或选择退出
· 开机自启动: 「系统设置 → 启动行为」中开启，登录后自动驻留托盘
· 命令行: colorful-cc-cli status   查看状态
          colorful-cc-cli auto     风扇交还 EC
          colorful-cc-cli fan 60   风扇固定 60%

【常见问题】
1. 装完但风扇/键盘不可控？
   → 绝大多数是安全启动尚未登记，按上面【重要】操作即可。
   → 仍不行：打开控制中心「诊断」页 → 加载模块 → 复制报告反映问题。
2. 模块日志: /var/log/colorful-control-center-kmod.log
   服务状态: sudo systemctl status colorful-control-center
3. 卸载: sudo apt remove colorful-control-center

【安全设计】
· 任何时候点「交还 EC 自动控制」即恢复出厂风扇策略
· 温度 ≥ 90°C 时程序自动接管为满转，防过热
· 手动模式转速下限 25%（EC 硬件限制，低于此值无效）
