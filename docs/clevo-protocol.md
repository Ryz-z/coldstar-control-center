# Clevo（蓝天）控制中心固件协议速查

> 本文是开发过程中对 Clevo（蓝天）“Control Center”固件接口的研究整理。
> 知识来源：[tuxedo-drivers](https://github.com/tuxedocomputers/tuxedo-drivers)（TUXEDO Computers，GPL-2.0+）以及公开逆向资料。
> 实测于 **Colorful 隐星 P15（P15 I5X1，BIOS 1.07.03COLO）**。不同机型的差异欢迎提 Issue/PR 补充。

## 1. 通信通道

固件把“控制中心”能力暴露在两条功能等价的通道上，一般优先使用 ACPI：

### 1.1 ACPI _DSM（设备 `CLV0001`）
- **DSM UUID**：`93f224e4-fbdc-4bbf-add6-db71bdc0afad`
- 调用方式：`func = 命令号`，`rev = 0`
- 参数：一个**只含 1 个整数**的 Package
- 返回：整数（个别命令返回缓冲区，如 `GET_SPECS`）

### 1.2 WMI（GUID `ABBC0F6D-8EA1-11D1-00A0-C90629100000`）
- `wmi_evaluate_method(GUID, instance=0, method_id=命令号, in=u32 参数 buffer)`
- **可用性探测**：调用 `0x52`（GET_BIOS_FEATURES_1），返回为整数且 ≠ `0xffffffff` → 接口可用
  （该 GUID 曾被其他 OEM 复用，建议都做这一校验）

本项目的内核模块 `clevo_cc.ko` 会依次尝试 ACPI DSM → WMI，并把“命令 + 参数 → 返回值”暴露给用户态（`/dev/clevo_cc`）。

## 2. 命令表

### 2.1 读取类
| 命令 | 名称 | 说明 |
|---|---|---|
| `0x01` | GET_EVENT | 读取并清除当前事件值 |
| `0x06` | GET_WEBCAM_SW | 摄像头开关状态（0/1） |
| `0x07` | GET_FLIGHTMODE_SW | 飞行模式开关状态 |
| `0x09` | GET_TOUCHPAD_SW | 触摸板开关状态 |
| `0x0D` | **GET_SPECS** | 返回缓冲区；`buf[0x0F]` = 键盘背光类型（见 §5） |
| `0x3D` | GET_KB_WHITE_LEDS | 白色键盘背光当前亮度 |
| `0x52` | **GET_BIOS_FEATURES_1** | `bit 0x00400000` = 三区 RGB 键盘；`bit 0x40000000` = 仅白光键盘 |
| `0x63` | GET_FANINFO1 | 风扇 1 信息 |
| `0x64` | GET_FANINFO2 | 风扇 2 信息 |
| `0x6E` | GET_FANINFO3 | 风扇 3 信息 |
| `0x7A` | GET_BIOS_FEATURES_2 | `bit 0x4000` = 白光键盘为 5 档亮度（否则 3 档） |

### 2.2 设置类（参数均为单个 u32）
| 命令 | 名称 | 参数格式 |
|---|---|---|
| `0x20` | SET_FLIGHTMODE_SW | 0 / 1 |
| `0x22` | SET_WEBCAM_SW | 0 / 1 |
| `0x27` | SET_KB_WHITE_LEDS | 亮度 0~255 |
| `0x2A` | SET_TOUCHPAD_SW | 0 / 1 |
| `0x46` | SET_EVENTS_ENABLED | 0 / 1 |
| `0x67` | **SET_KB_RGB_LEDS** | 见 §4 |
| `0x68` | **SET_FANSPEED_VALUE** | 见 §3 |
| `0x69` | **SET_FANSPEED_AUTO** | 0（恢复 EC 自动调速） |
| `0x79` | OPT（杂项） | `0x19000000 \| profile` → 设置性能预设 |

## 3. 风扇控制

### 3.1 设置转速（`0x68`）
```
arg = fan0 | (fan1 << 8) | (fan2 << 16)     # 每个风扇 1 字节，0~255
```
- **EC 有效下限约 25%（≈64）**：低于该值会被固件按 0 或 25% 处理，应用层建议钳制到 `≥64`
- 发送后建议 `sleep(100ms)` 等待 EC 生效
- 恢复出厂自动策略：`0x69`（参数 0）

### 3.2 读取（`0x63` / `0x64` / `0x6E`）
返回 u32，高 16 位 ≈ 当前转速（RPM），低 8 位 ≈ 当前占空比。
（转速也可以直接从 hwmon 的 `acpi_fan` 设备读，更简单）

## 4. 键盘 RGB（`0x67`）

### 4.1 分区颜色
```
arg = 区域子命令 | 颜色线序值
区域子命令: 0xF0 = 区0(左)   0xF1 = 区1(中)   0xF2 = 区2(右)   0xF3 = 已知机型未使用
```
**颜色线序为 `B<<16 | R<<8 | G`**（注意：不是常见的 RGB / BGR 排列）：
```
输入颜色 (r, g, b)，0~255
线序值 = (b << 16) | (r << 8) | g
```
- **单区 RGB 机型**（spec `0x06`）存在硬件缩放：红通道 ×180/255、蓝通道 ×200/255
- **三区 RGB 机型**（spec `0x02`）无需缩放

### 4.2 亮度
```
arg = 0xF4000000 | (亮度 & 0xFF)     # 亮度 0~255
```

### 4.3 背光开关
```
开: 0xE0000000 | 0x07F001  = 0xE7F001
关: 0xE0000000 | 0x003001  = 0xE03001
（直接作为 0x67 的参数发送）
```

### 4.4 硬件灯效
把下列常量**直接作为 0x67 的参数**发送（会覆盖静态颜色）：

| 灯效 | 值 |
|---|---|
| 自定义（静态） | `0x00000000` |
| 呼吸 | `0x1002A000` |
| 循环 | `0x33010000` |
| 舞动 | `0x80000000` |
| 闪烁 | `0xA0000000` |
| 随机色 | `0x70000000` |
| 节拍 | `0x90000000` |
| 波浪 | `0xB0000000` |

## 5. 键盘类型识别

优先级从上到下：

1. **`0x0D`（GET_SPECS）缓冲区偏移 `0x0F`**：

   | 值 | 类型 |
   |---|---|
   | `0x00` | 无背光 / 未知 |
   | `0x01` | 仅白光（固定色） |
   | `0x02` | 三区 RGB |
   | `0x06` | 单区 RGB |
   | `0xF3` | 单键 RGB |

2. **回退 `0x52`（位掩码）**：`bit 0x00400000` → 三区 RGB；`bit 0x40000000` → 仅白光
3. **白光档位**：`0x7A` 的 `bit 0x4000` → 5 档亮度（否则 3 档：0/1/2）

## 6. 性能预设（`0x79`）

```
arg = 0x19000000 | profile
profile: 0 = 省电   1 = 安静   2 = 性能   3 = 影音
```

## 7. 注意事项

- 所有固件调用请**串行化**（本项目内核模块内部已加互斥锁）
- 按机型/BIOS 版本差异：返回 `0xffffffff` 一律视为“不支持”
- 读命令 `0x0D` 偶发返回空，建议重试 2~3 次
- 本文欢迎 PR 补充其他机型差异 —— 让更多白牌 Clevo 玩家用上 Linux 控制中心
